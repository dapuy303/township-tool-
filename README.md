# Township Tool V2

Versi gaming yang lebih lengkap untuk companion/perencanaan.

## Fitur
- Dashboard gaming
- Level + XP
- Resource inventory + progress kebutuhan
- Pencarian & filter resource
- Preset nama item
- Kalkulator produksi multi-pabrik
- Timer produksi real-time
- Riwayat produksi
- Task/mission board + XP
- Dark/light mode
- Export & Import backup JSON
- LocalStorage
- PWA/offline cache
- Tidak mengakses, meretas, atau memodifikasi akun/server/game

## Upload ke GitHub Pages
1. Buka repository `township-tool`.
2. Pilih **Add file → Upload files**.
3. Upload/replace semua file dari folder ini ke root repository.
4. Commit ke branch `main`.
5. Tunggu deployment `github-pages` selesai.
6. Buka `https://dapuy303.github.io/township-tool/`.

Jika browser masih menampilkan versi lama, refresh dan hapus cache situs bila perlu.
