TOWNSHIP TOOL - GAMING PWA

Versi ini memiliki dashboard bergaya game, statistik, navigasi bawah,
resource tracker, production timer, localStorage, dark gaming UI, dan offline cache.

Cara pakai:
1. Upload folder ini ke hosting statis HTTPS.
2. Buka alamatnya di Chrome Android.
3. Pilih "Tambahkan ke layar utama" atau "Install app".
4. Jalankan seperti aplikasi.

Catatan: tool ini adalah companion/perencana. Tidak berisi fitur pembobolan akun,
server, atau manipulasi game.
